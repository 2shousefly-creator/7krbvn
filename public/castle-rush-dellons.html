02 / TRANG BỊ

🛡️ Trang bị & build

Ryan and Rachel: if unsure about crit, use 85-87% crit + crit refine accessory 10%; after getting a high score, crit can be lowered for a bigger score

Deo: Skill 1 must be upgraded so the CDM buff increases

Eileene: must be Awakened for the extra stats and have her passive skill upgraded; any Transcendence level works.

03 / THỨ TỰ SKILL

🎯 Thứ tự skill từng Wave

Chuỗi rotation do tác giả video ghi trong bình luận ghim (Atas = skill trên / Skill 2, Bawah = skill dưới / Skill 1).

Wave 1: Ryan bottom skill.

Wave 2: Rachel bottom skill.

Wave 3: Eileene bottom > Biskuit buff > Rachel top > Ryan top > Deo bottom > Rachel bottom > Eileene bottom > Ryan bottom > Rachel top > Ryan top > Biskuit buff > Rachel bottom > Ryan bottom > Deo bottom > Rachel top > Ryan top > Rachel bottom > Ryan bottom. (Atas = top skill / Skill 2, Bawah = bottom skill / Skill 1.)

04 / LƯU Ý

💡 Lưu ý khi đánh

  • Speed tuning: Deo 33 > Biskuit 31 > Eileene 29 > Rachel 29 > Ryan 29.
  • Rachel's ATK must be 100+ higher than Eileene's and Deo's. Otherwise Rachel does not get the Biskuit buff (2nd highest ATK) and does not get Ryan's cooldown reduction, which changes the cooldowns and breaks the rotation. Test in practice mode first if unsure.
  • Pinned comment also lists redeem code 7KNIGHTSMAZE8 (1x Brilliant Skill Stone and 50 Raid Tickets) — time-sensitive, may already be expired.
