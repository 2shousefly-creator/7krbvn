02 / TRANG BỊ

🛡️ Trang bị & build

Biskuit: Avenger set + DoT accessory (bleed/burn/poison)

Orly/Lina: Avenger set + DoT accessory if Nezha is TC2 or higher; if Nezha is below TC2 use Paladin/Gatekeeper set + DoT accessory to survive

Evan: any set, must use a DoT accessory

Nezha TC6 recommended (has Ignore DEF; TC0-TC5 should use the alternate rotation linked in the pinned comment)

Lina must be TC6

Orly must have Skill 1 and basic attack upgraded

For PvE DPS exclusive equipment, Damage Amplification tuning is better than ATK at the same grade

Crit-refine vs single-triple accessory: crit-refine only wins if CDM is 18%+ higher (or 12% CDM + 5% ATK) at equal ATK (example in comment: crit build ATK 4.3k CDM 312% still loses to single-triple ATK 4.3k CDM 300%).

03 / THỨ TỰ SKILL

🎯 Thứ tự skill từng Wave

Chuỗi rotation do tác giả video ghi trong bình luận ghim (Atas = skill trên / Skill 2, Bawah = skill dưới / Skill 1).

Rotation B (Nezha + Lina).

Wave 1: Biskuit buff > Miho top.

Wave 2: Nezha bottom.

Wave 3: Nezha top > Biskuit top > Lina top > Miho bottom > Miho top > Nezha bottom > Nezha top > Biskuit top > Biskuit buff > Miho bottom > Nezha bottom > Nezha top > Lina top > Biskuit top > Miho bottom > Nezha bottom > Nezha top. (Arrows in the original comment: Atas = top skill / Skill 2, Bawah = bottom skill / Skill 1.)

04 / LƯU Ý

💡 Lưu ý khi đánh

  • Speed tuning: Miho > Nezha > Biskuit > Orly > Evan (rotation A); Miho > Nezha > Biskuit > Lina > Evan (rotation B).
  • Max score: Orly rotation 14,431,573 vs Lina rotation 14,335,905 (Orly higher by 95,668 with identical Nezha equipment).
  • Orly rotation is delay-prone: DoT must be triggered from early turns (below Turn 14). Triggering 1 DoT means delay is RNG; triggering 2 DoTs on different targets means no delay. Author suggests trying the Orly rotation 3 times, then switching to the Lina rotation in the second battle of the video.
  • Nezha's crit passive and Orly's crit passive do NOT stack: with Orly in the team, Nezha's crit stays 33%, not 33% + 17%.
  • DoT accessories (bleed/burn/poison) smooth the rotation: each DoT that pops on an enemy basic attack slightly changes the animation timing and prevents skill delay. Trigger chance per accessory: B6 15%, B5 10%, B4 5%. Using 3 DoT accessories makes the rotation safe; fewer means RNG. Each triggered DoT also deals around 3k damage per turn.
  • If Nezha is below TC2, Biskuit must use a Guts accessory or Nezha will die.
  • Nezha TC0-TC5 is not recommended for the rotation in this video because the first skill used in Wave 3 is Nezha's top skill while the boss is still at 100% HP, so damage is lower without Ignore DEF (TC6).
