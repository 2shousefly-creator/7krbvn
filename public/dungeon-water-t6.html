03 / LƯU Ý

💡 Lưu ý khi đánh

  • Strategy: bring Freeze immunity (Lina or Fengyan — transcript renders the first name as 'Lania'; the team uses Lina as healer and Fengyan standing) and Unable to Recover, because the mushroom heals itself.
  • Bai Jiao can apply Unable to Recover, but only if his skill is enchanted — the creator's Bai Jiao is plain, so he does not rely on it.
  • Damage comes from Poison (percent-HP damage — the biggest damage source here).
  • Description tip: if Bai Jiao's skill is enchanted it is better (mushroom cannot heal); Lina can be swapped for Chloe if your damage is lacking.
  • Skill priority (repeat battle): Biscuit buff -> Bai Jiao bottom -> Dongyoung top (Poison + potion) -> Dongyoung bottom (shield) -> Dongyoung Awakening -> Bai Jiao top (also heals) if not dead yet.
